# Rounds are subagents of the orchestrator's harness

A round is a subagent of the session running `/implement-spec`, spawned with whatever that harness calls its fresh-context worker, in a worktree the orchestrator cut. This supersedes ADR-0001 and ADR-0002: detached CLI processes bought survival past the orchestrator's session, but under serial rounds (ADR-0003) a dead orchestrator ends the run either way, and the detach, launch, resume, review, watch, and invocation scripts cost a Python and process-inspection layer with no Windows form and a continue flag that resumed the wrong session once a review had run in the worktree. Claude Code, Grok, and Codex all have subagents, so the skill names the mechanism and not the product, and the launcher and CLI recipe go with the scripts. A round's output stays out of the orchestrator's context: it holds the ledger and a suite tail, nothing else.
