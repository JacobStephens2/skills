### Issue tracker

GitHub Issues in this repo (`gh`). See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical role names as labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

No root glossary. `implement-spec` has `implement-spec/CONTEXT.md` and ADRs under `implement-spec/docs/adr/`. Elsewhere, proceed silently. See `docs/agents/domain.md`.
